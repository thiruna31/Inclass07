## Run locally

PHP must be installed, or use a PHP-enabled development environment.

1. Extract the ZIP file.
2. Open a terminal in the extracted `CSC4370_PHP_Functions` folder.
3. Run:

   ```bash
   php -S localhost:8000
   ```

4. Open `http://localhost:8000` in your browser.
5. Visit each mission from the home page and verify the output.

Do not open `index.php` by double-clicking it; that does not execute PHP. If `php` is not recognized, install PHP or use a PHP-enabled environment approved for your course.
